Exercícios HTML e CSS — PROA
Repositório desenvolvido durante o curso do Instituto PROA, reunindo exercícios e práticas de HTML e CSS realizados ao longo dos estudos.

O objetivo deste projeto é praticar os principais conceitos de desenvolvimento web, evoluindo gradualmente desde estruturas HTML básicas até projetos mais completos.

Conteúdo
O repositório contém 29 exercícios e um projeto final:

exercicio01 até exercicio29 — exercícios práticos de HTML e CSS
ProjetoFinal — projeto desenvolvido para aplicar os conhecimentos aprendidos durante o curso
Tecnologias utilizadas
HTML5 — estruturação das páginas
CSS3 — estilização e criação de layouts
Conceitos praticados
Durante o desenvolvimento dos exercícios, foram trabalhados conceitos como:

Estrutura básica de documentos HTML
Tags semânticas
Textos, links e imagens
Listas e tabelas
Formulários
Classes e IDs
Cores, fontes e espaçamentos
Bordas e backgrounds
Seletores CSS
Flexbox
Organização e estilização de layouts
Desenvolvimento de páginas web

Como executar
Clone o repositório:
git clone https://github.com/Larifcoelho/exercicios-html-css-proa.git

Acesse a pasta do projeto:
cd exercicios-html-css-proa

Escolha um dos exercícios e abra o arquivo index.html no navegador.
Também é possível utilizar ferramentas como o Live Server no Visual Studio Code para visualizar as páginas durante o desenvolvimento.

Sobre o projeto
Este repositório faz parte da minha jornada de aprendizado em desenvolvimento web e serve como registro da evolução dos meus conhecimentos em HTML e CSS.

Os exercícios foram desenvolvidos de forma progressiva, colocando em prática os conteúdos estudados durante o curso do Instituto PROA.
